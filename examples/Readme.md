# Examples

You can build all of the examples by running `zig build all` in this folder. The executables will be in the `zig-out\bin` in this folder.

Within a specific example's folder, run `zig build run` to run that example.

- [count primes](count_primes/build.zig)
- [nth prime](nth_prime/build.zig)
- [prev prime](prev_prime/build.zig)
- [primes array](primes_array/build.zig)
- [primesieve iterator](primesieve_iterator/build.zig)
